## 0.4.0 (2026-11-16)

- Equilibrium gap and SDF synergy agents (`quantum_projection/equilibrium.py`, `sdf_synergy.py`, `synergy_agents.py`, `unified.py` v040 claims; 23 new tests, suite now 143): the optimization variable changes from empathy entropy to the equilibrium gap (max profitable unilateral deviation, 0 at equilibrium), because claim (vi) FAILED on saturation. The checker (validate_game, analyze_profile, find_pure_equilibria) is vendored from finite-game-equilibria v0.1.0 (DOI 10.5281/zenodo.23530287, commit 11698948) and checked against that package's README demos in the tests. The game: players are the 3 solar systems, actions δ ∈ {−0.05, 0, +0.05}, payoffs are per-system marginal contributions (leave-one-out) to the joint inside-coverage of the self-known region. SDF synergy = joint region coverage − mean per-system coverage (coverage reading stated in the module; the pooled-avatar-fraction reading is identically the mean for equal-sized systems and is named and rejected). One synergy agent per system chooses δ by greedy coordinate descent on the gap over a payoff table built from 27 lookaheads per generation; empathy entropy stays a diagnostic only.
- Claims (x)–(xii), pre-registered, seed 11, 3 systems × 8 avatars, thresholds set from the seed-7 pilot: (x) equilibrium gap — FAIL (gap 0.0 at every generation, agent and zero alike; first non-trivial gen 6; the equilibrium was never earned because it was never out of reach); (xi) SDF synergy — FAIL (mean synergy final 3 gens 0.0217 vs 0.0217, gain 0.0); (xii) stability — PASS (first reach gen 6, held 4; landed [0, 0, 0], label "trap": 12 equilibria in the final table, best synergy 0.0362 at [−0.05, −0.05, 0.05] vs landed 0.0290 — the oes-coordination-lab trap, reproduced: the safe equilibrium holds while a better-synergy equilibrium exists that no single system gains by deviating to). Pilot (seed 7) differed: (x) and (xii) passed there with the agents intervening at gens 7–9 and landing "efficient" (synergy 0.0870 vs zero 0.0725). Structural findings: the population is heterogeneous (a few avatars are born with stored variants — "fast healers" — one pilot avatar had D = 0.308 at generation 0); coverage is set by birth variants and the healing curve, not by attunement; SDF synergy is transient (peaks mid-healing, falls as the population converges on the stored state). Empathy entropy diagnostic: gain 0.0, still saturated, confirming (vi). A synergy-seeking tie-break among zero-gap profiles is an open question, not a fix applied silently.
- Honest limits: classical emulation; Nash over a finite 3-action pure-strategy game says nothing about mixed equilibria, learning dynamics, or real systems; the equilibrium is a property of the supplied payoff table; SDF synergy is a defined model quantity. TISU excluded; a test enforces the exclusion. Headline not allowed.

## 0.3.0 (2026-11-15)

- Multi-solar-system eureka cascade (`quantum_projection/solar_systems.py`, `eureka_agent.py`, `sdf.py`, `crystallize_events.py`, `longrun.py`, `unified.py` v030 claims; 32 new tests, suite now 120): three populations of DNA avatars coupled by a bounded 0.02 mix; a eureka agent (Yang observer + Yin calibrator, δ ∈ [−0.05, 0.05] on λ(1+δ)) whose objective is empathy entropy H over the measured love distribution (love = concurrence across the stored/non-stored split, 2√(D(1−D))); the signed distance field of self-knowing (sdf = √(1−D) − √(1−τ), τ = 0.5); crystallize calibration events scored with Crystallize's exact formulas (Brier, 100·(1−4·Brier) − 0.8 per sample); the 500-generation long run (5000 in progress in the background).
- Claims (v)–(ix), pre-registered, seed 11, 3 systems × 8 avatars: (v) solar systems — PASS (healing 0.1013 coupled vs 0.1076 uncoupled; support gain 0.1029, shocked 0.6487 vs 0.7516; gap narrows 0.5438 vs 0.6463; others 0.1049 vs 0.1053 — what spreads is support, not harm); (vi) eureka agent — FAIL (mean H 4.5849 vs 4.5849, gain −0.0001, required ≥ 0.02: empathy entropy is already saturated at 99.998% of its log2(24) ceiling, so the lever has nothing to move; total love peaks at generation 7, exactly the SDF crossing generation); (vii) SDF — PASS (mean sdf 0.2895 → −0.3889, fraction inside 0.00 → 1.00, crossing gen 7); (viii) crystallize — PASS (10 events, mean Brier 0.0000, 960.0 points — the fall is nearly deterministic given the state); (ix) long run — PASS at 500 gens (novelty 0.0225, discord 0.0050, cumulative 667 → 3246, no creativity horizon); the 5000-generation extension FAILS on novelty (0.0000 at gen 5000, creativity horizon at generation 1225, cumulative reaching the exact 4096-sequence ceiling at generation 4140) — eternal recreation has a measured limit in this toy space.
- Two design corrections measured on the pilot and kept: the correlation check for contagion was rejected (per-generation discord changes correlate ~0.78 even uncoupled — the shared healing curve, not the coupling), replaced by a controlled shock; and the SDF region is fixed in state space, so what is measured is the population's occupancy and crossing, not the region moving.
- Also fixed: README.md and REPORT.md listed the wrong healthy templates (`CCGGAA`, `GCGCGC`, `TATATA`); the code stores `AATTAA`, `ATATAT`, `TAAATA`, `AATATT` — the docs now match the code.
- Honest limits: classical emulation; the agent is a bounded optimizer, not a mind; empathy entropy is entropy over a measured love distribution, not human empathy; the SDF is a field over a toy state space; crystallize events are checkpoints, not guarantees; "eternal" means an unbounded run tested to N generations, not literal infinity. ## 0.2.0 (2026-11-15)

- DNA-avatar generational cascade (`quantum_projection/dna_avatars.py`, `trauma.py`, `planetary.py`, `creativity.py`, `unified.py`; 23 new tests, suite now 88): toy DNA sequences (6 bases, A/C/G/T, 2 qubits per base = 12-qubit basis states) in one membrane; self-knowing D = ⟨ψ|P|ψ⟩ per avatar via a Gram–Schmidt projector basis (the D idea from symmetry-entropy / the Faggin field bridge, re-implemented in pure Python); discord = 1 − D per generation; self.cycle where each generation's output feeds the next; planetary diversity, novelty and the E = hν spectrum (h = 1 model units) per generation; unbounded generation rule for infinite creativity.
- Cascade claims, all PASS, pre-registered (seed 11, 8 avatars): (i) avatar D — stored 1.0, kernel 0.0, half 0.5; (ii) healing — mean discord 0.9932 → 0.0894 over 10 generations (ratio 0.090, monotone fall 10/10 steps), saturating at 0.0050 (D = 0.9950) from generation 20; (iii) planetary — min diversity 4, min novelty 0.124, mean energy 2.38 → 1.00 (−58%), peak energy 3 → 1; (iv) creativity — 50 generations, min novelty 0.080, cumulative distinct 36 → 667 strictly increasing every generation, mean novelty 0.149.
- Healing uses a partial projection (λ = 0.3): a full recall would heal instantly because an orthonormal W is a projector. Each avatar keeps a retained healthy sequence at small weight, and mutation never touches stored variants, so the projection can only amplify weight already present.
- Defect found and fixed during testing: the Gram–Schmidt projector called the inner product inside the element loop (O(n²) per update, ~11 s per D call); the coefficient is now hoisted, D takes ~0.02 s. Values were correct before the fix; only the speed changed.
- Honest limits: classical emulation; DNA avatars are toy encodings, not biology; trauma healing is a measured fall in a defined model quantity, not a therapeutic claim; planetary evolution is a population model, not Earth science; infinite creativity is unbounded generation inside the model. ## 0.1.0 (2026-10-21)

- Archived on Zenodo: version DOI [10.5281/zenodo.23530281](https://doi.org/10.5281/zenodo.23530281), concept DOI [10.5281/zenodo.23530280](https://doi.org/10.5281/zenodo.23530280).
- First commit: the package exactly as received (`spec/`).
- Authorship: Jean-François Brisson. Mun Seok Lee is credited in the acknowledgements only.
- Wording: "collapse" is now "projection onto the stored subspace". With orthonormal patterns W is a projector, so recall reaches its fixed point in one step and the recalled fidelity equals the Born weight; both are measured and tested. The default `recall` is now one step (was 25).
- Measured: with non-orthogonal patterns, repeated recall converges to W's dominant eigenvector and loses the one-shot decision (75% of winners change at σ = 0.25).
- Ket/bra split documented as the same inner product; tests now compare complex overlaps, phases included, instead of magnitudes only.
- Single-seed checks replaced by 200-seed sweeps over five σ values for Bell classification, |00⟩ vs |+0⟩ and coarse-grained 3-qubit states, with unstored probes (Ψ−, |01⟩, |001⟩) and Haar-random controls. The "20/20" claim is restated with its seed range.
- Coarse-graining: documented and tested as projecting the merged qubit onto |+⟩; the qubit is now selectable (default 0, the least-significant bit, as before).
- Removed the unused `ry` gate and the unused `n` arguments of `apply_1q` and `apply_cnot`. Added `ValueError` checks for empty pattern lists, length mismatches, zero-norm and non-finite vectors, bad qubit indices and probes orthogonal to every pattern.
- The coarse-grained GHZ check, whose only alternative was a noisy copy of GHZ, is replaced by distinct stored states (W, |000⟩, |+++⟩).
- DESIGN.md: neutral wording in the limits section; headings that overstated the checks replaced by measurements.
- Added a package layout, a CLI that prints the sweeps, 65 pytest tests, CI on Python 3.10 to 3.13, README, CITATION.cff and .zenodo.json.
